# Program scorecard: the assembly line, end to end

Every number is read from a completed study's real result tables. Trial counts are the configurations actually evaluated; clearing DSR means the deflated Sharpe exceeds 0.95 (genuine after accounting for the number of trials). Property studies (bars, frac-diff) are statistical and cost-free by nature, so they carry no strategy DSR gate.
